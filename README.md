# چاپ‌یار | سامانه برآورد قیمت چاپ و بسته‌بندی

نسخه اولیه قابل اجرا با Python، Django و PostgreSQL، مناسب شروع و توسعه در VS Code.

## امکانات نسخه حاضر
- داشبورد خلاصه مشتریان، قیمت‌های پایه و برآوردهای اخیر
- ثبت برآورد برای جعبه، لیبل، کاتالوگ، بروشور، ساک دستی و سایر محصولات
- محاسبه هزینه مواد، پرت، چاپ، زینک/آماده‌سازی، خدمات پس از چاپ، قالب، حمل، دستمزد، سربار، سود و مالیات
- آرشیو و جست‌وجوی برآوردها بر اساس نام مشتری، عنوان یا نوع محصول
- مرکز قیمت‌های پایه با دسته‌بندی، واحد، تأمین‌کننده، تاریخ اعتبار و لینک منبع
- پنل Django Admin برای مدیریت کامل مشتریان، نرخ‌ها و وضعیت برآوردها
- رابط فارسی راست‌چین و گزارش قابل چاپ از مرورگر

## نیازمندی‌ها
- Python 3.11 یا جدیدتر
- PostgreSQL 14 یا جدیدتر (اختیاری برای شروع محلی؛ اگر متغیر DB_NAME تنظیم نشود SQLite استفاده می‌شود)
- VS Code و افزونه Python

## راه‌اندازی در VS Code

### 1) باز کردن پروژه
فایل ZIP را استخراج کنید و پوشه `chap_cost_estimator` را در VS Code باز کنید.

### 2) ساخت محیط مجازی
در ترمینال VS Code:

Windows PowerShell:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

macOS / Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3) تنظیم پایگاه داده
برای شروع سریع، فایل `.env.example` را به `.env` کپی کنید. برای PostgreSQL مقدارهای `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` را مطابق تنظیمات خود اصلاح کنید. اگر `DB_NAME` در `.env` تنظیم شده باشد، برنامه از PostgreSQL استفاده می‌کند. اگر می‌خواهید ابتدا بدون PostgreSQL آزمایش کنید، `DB_NAME` را حذف یا خالی کنید تا SQLite استفاده شود.

نمونه ساخت پایگاه داده در psql:
```sql
CREATE DATABASE chapcost;
CREATE USER chapcost_user WITH PASSWORD 'change-this-password';
GRANT ALL PRIVILEGES ON DATABASE chapcost TO chapcost_user;
```
در برخی نسخه‌های PostgreSQL ممکن است لازم باشد مالکیت schema نیز به کاربر داده شود:
```sql
\connect chapcost
GRANT ALL ON SCHEMA public TO chapcost_user;
```

### 4) مهاجرت و ساخت مدیر
```bash
python manage.py makemigrations estimator
python manage.py migrate
python manage.py createsuperuser
```

### 5) اجرای محلی
```bash
python manage.py runserver
```
سپس آدرس `http://127.0.0.1:8000/` را باز کنید. پنل مدیریت در `http://127.0.0.1:8000/admin/` است.

## گردش کار پیشنهادی
1. وارد `/admin/` شوید و چند مشتری ایجاد کنید.
2. از «قیمت‌های پایه» نرخ مواد اولیه و سایر اقلام را اضافه کنید.
3. از «برآورد جدید» مشتری، تیراژ، ابعاد، مشخصات رنگ، هزینه‌های چاپ و خدمات را وارد کنید.
4. گزارش برآورد را باز کنید و برای چاپ از دکمه «چاپ گزارش» استفاده کنید.
5. برای پیدا کردن برآوردهای قبلی از بخش «برآوردها» جست‌وجو کنید.

## نکات مهم محاسبات
- تمام مبالغ این نسخه به **تومان** هستند. اگر منبعی قیمت را به ریال اعلام می‌کند، پیش از ورود تبدیل کنید.
- در محاسبه مواد، اگر واحد قلم ماده اولیه «کیلوگرم»، `kg` یا «کیلو» باشد، قیمت واحد به عنوان قیمت هر کیلوگرم تفسیر می‌شود و مصرف بر اساس گرم برای هر محصول محاسبه می‌شود. برای واحدهای دیگر، قیمت ماده به ازای هر محصول با ضریب پرت محاسبه می‌شود. برای کاربرد واقعی بهتر است منطق مصرف مواد مطابق فرم‌بندی، ابعاد ورق، تعداد محصول در هر شیت، جهت الیاف و پرت دستگاه توسعه یابد.
- «حاشیه سود» در کد بر اساس سهم سود از قیمت فروش محاسبه می‌شود، نه صرفاً درصد افزوده‌شده روی هزینه.
- قیمت‌های نمونه بازار به‌صورت خودکار از سایت‌ها جمع‌آوری نمی‌شوند؛ قیمت‌ها باید توسط کاربر مجاز ثبت و تاریخ‌گذاری شوند. وب‌سایت‌ها ممکن است قیمت را تغییر دهند و شرایط اعلام قیمت یکسان نیست.
- این نسخه برای استفاده آزمایشی و توسعه داخلی است، نه قیمت‌گذاری قطعی بدون بازبینی متخصص. محاسبه فرم چاپ، تعداد زینک، سطح پوشش مرکب، نرخ دستگاه، هزینه کلیشه، لمینت، UV، طلاکوب، دایکات، چسب، صحافی و کنترل کیفیت در پروژه‌های پیشرفته باید با پارامترهای دقیق‌تر پیاده‌سازی شوند.

## مدل داده
- `Customer`: نام، تلفن، ایمیل، نشانی و یادداشت مشتری
- `PriceItem`: دسته، عنوان، واحد، قیمت، تأمین‌کننده، تاریخ اعتبار و منبع
- `Quote`: مشخصات سفارش، ابعاد، تیراژ، مصرف ماده، پرت، رنگ، هزینه‌های مستقیم، سربار، سود، مالیات، وضعیت و یادداشت

## پیش از انتشار واقعی
- `DJANGO_DEBUG=0` و یک `DJANGO_SECRET_KEY` امن تنظیم کنید.
- `ALLOWED_HOSTS` را محدود کنید.
- HTTPS، پشتیبان‌گیری PostgreSQL، ثبت رویدادها، نقش‌های کاربری و کنترل دسترسی را تنظیم کنید.
- آزمون‌های محاسباتی و بازبینی واحدها/مالیات را با مدیر تولید و حسابداری انجام دهید.
- از اطلاعات مشتریان واقعی در محیط توسعه عمومی استفاده نکنید.
